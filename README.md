# DSH Connect

HarmonyOS 原生 AI 客户端与 DSH Desktop 连接工具。

本仓库仅用于发布安装包、版本说明和安装指南，不包含手机客户端源码。手机客户端为闭源产品；电脑端插件单独维护。

## 发布状态

目前正在准备侧载测试包，尚无经验证可供普通用户直接安装的发行版。

现有 0.10.0 应用市场签名包不作为侧载包提供。HarmonyOS 原生应用安装受签名和设备授权限制，GitHub 下载并不代表可直接安装。指定设备发布包仅适用于其 Profile 授权的设备，调试包需要相应开发调试环境，不承诺任意设备安装。

## 功能与数据

支持自行配置模型服务的 AI 聊天、图像工作室及 DSH Desktop 电脑会话连接。模型服务需用户自行配置，可能产生第三方费用。请只连接可信模型服务及已授权电脑。

API Key、签名私钥及证书密码不会随安装包或本仓库发布。安装说明会随实际验证通过的发行版提供。

本项目独立维护，非华为或模型服务商官方应用，尚未通过华为应用市场上架审核。
